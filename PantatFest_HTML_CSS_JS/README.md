# PantatFest — HTML/CSS/JavaScript version

A static, multi-page festival showcase website. It does not use PHP, a database, WAMP, XAMPP, Node.js, or a backend.

## Open in Microsoft Edge
1. Extract the ZIP file.
2. Open the `PantatFest_HTML` folder.
3. Double-click `index.html` (or right-click it and choose Microsoft Edge).
4. Navigate using the menu.

You can also open the folder in VS Code and use the Live Server extension if installed. Live Server is optional.

## Registration demo
The registration form stores submissions in the browser's `localStorage`. Data stays on that browser/device only. It is not sent to festival organizers and is not shared with other visitors. Do not use this for real personal information or official registration.

## Customize
- Edit page content in the `.html` files.
- Edit styles in `css/style.css`.
- Edit interactions in `js/script.js`.
- Add approved photos in `images/` and update gallery/hero backgrounds.
- Verify all dates, history, official contact details, and event information with the Municipality of Zarraga before publishing.

## Internet
The website's main layout works offline. The hero uses an external Unsplash image and the stylesheet optionally imports Google Fonts, so those visuals/fonts need an internet connection. Replace with local approved assets for a fully offline version.
